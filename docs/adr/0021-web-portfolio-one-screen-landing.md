# 0021. 웹 포폴 랜딩 — 한 화면 대시보드, 유리 뒤 3D 세계

날짜: 2026-08-06

## 상태

승인됨 (0020의 랜딩 부분을 대체. 여정 구조는 유지)

## 맥락

CodeBucks 이식 후에도 랜딩 퀄리티가 낮았다. 6개 관점(웹디자인·HR·시각계층·데이터비즈·마감·입체감) 서브에이전트 리뷰가 수렴한 원인: 같은 숫자(1년 2개월·191명)가 한 화면에 3~4회 반복되어 ~500px을 낭비하고 CTA가 폴드 밖으로 밀림, 데이터 없는 conic 도넛 링(가짜 차트), 한글 광폭 자간, 산호 글로우 얼룩, 그리고 **유일한 차별점인 3D 세계를 랜딩이 불투명 배경으로 가리는 구조**.

## 결정

- **한 화면**: 랜딩 `height: 100vh`, 스크롤 없이 전부 표시. 구성 = 히어로(초대형 이름+역할+KPI 3개+걷기 CTA) → 소개문단|사실카드(경력·학력·연락처) → 커밋차트|도구 → 문 2개(포폴·이력서).
- **사실 1회 원칙**: 각 수치는 화면에 정확히 한 번(정본 = 히어로 KPI). 빅넘버 카드·STATS 카드·도넛 링 삭제.
- **유리 뒤 세계**: 랜딩 배경을 반투명 스크림으로 강등해 3D 해안 세계가 카드 유리 뒤로 비침 + 랜딩 한정 카메라 마우스 패럴랙스. 글래스모피즘이 실제로 성립하는 구조.
- **광원 통일**: 우상단 하나(3D 태양과 일치). 그림자는 좌하단, 청록-네이비 틴트. 산호 글로우 삭제(하늘색과 섞여 얼룩이 됨).
- **커밋 차트 자체 렌더**: 외부 위젯 대신 ECharts 주 단위 6주 바 차트, 클라이언트에서 GitHub 집계 API를 fetch(실패 시 마지막 확인값). 실데이터 검증: 12주 창은 앞 6주가 0, 월 단위는 7개월 연속 0이라 부채 — 6주 창만 정직하면서 유리.
- **타이포 시스템**: 한글 광폭 자간 금지(라틴 캡스만 허용), 크기 스케일 11/13/15/17/…px, 폰트 웨이트 400/500/700만 로드.
- **약점 비노출**: 학력은 "국립한경대학교 졸업" 한 줄 — 학점·"비전공 출발" 문구 삭제.

## 결과

- 랜딩 1589px → 1080px(정확히 한 화면). 걷기 CTA는 히어로 우측 상시 노출.
- 기각: 도넛 링 실수치화(52주 게이지 — 커밋 밀도가 초라해 자폭 위험), 커밋 그래프 삭제안(자체 렌더로 해소), 뉴모피즘.
- 직함("데이터 엔지니어")-증거(인프라 경력) 불일치는 HR 리뷰에서 최상위 지적 — 문구는 사용자가 직접 수정 예정.
