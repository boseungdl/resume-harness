# 0019. 웹 포폴 형식 전환 — 스크롤 3D를 버리고 "한 붓 초상"으로

날짜: 2026-08-06

## 상태

승인됨 (ADR-0018의 '스크롤 3D 챕터' 형식 결정을 대체. 포폴 이원화·독자·콘텐츠 원칙은 0018 유지)

## 맥락

ADR-0018의 스크롤 3D(파티클 주인공) 프로토타입은 두 가지 이유로 기각됐다.

1. **유의미성이 읽히지 않음** — 파티클 대형의 의미는 해설이 있어야 보였다("알고 보면 알지만 단순 모래밭"). 해석이 필요한 순간 바쁜 독자에겐 장식이다.
2. **차별화 소멸** — Fable급 모델 등장 이후 스크롤 3D 웹포폴은 누구나 만드는 1차 유행 문법이 됐다. "절대다수가 하는 건 하지 않는다"가 새 제약.

추가 요구: 보상·변화를 알기 위해서라도 **내용을 꼼꼼히 읽게 만드는** 게임적 동기(스크롤-온리는 공짜라서 대충 넘긴다), 단 조작 부담은 계속 0에 가까울 것.

## 결정

**한 붓 초상**: 흰 종이 무대(다크 테크 문법의 정반대). 화면 한쪽에 이야기 7문단, 다른 쪽 종이 위에서 펜이 초상 선화를 그린다. 핵심 규칙 — **펜은 독자가 읽는 속도로만 움직인다**(문단이 화면 중앙에 머무는 동안만 해당 부위가 그려짐). 건너뛰면 선이 끊긴 초상이 남고, 엔딩이 "여기까지가 읽어주신 만큼의 저입니다"라는 거울이 된다. 완독 시 낙관(붉은 도장)이 찍히며 "나머지는 만나서 그리시죠" + 연락처.

- 읽기 자체가 게임의 행동이자 보상 조건 — 꼼꼼히 읽게 만드는 동기가 형식에 내장.
- 3D 폐기: 이 컨셉에서 3D는 도구로서 불필요. 퀄리티는 선화의 생명감·종이 질감·타이포에 투자.
- AI 활용 증명(SK하이닉스 등 채용 트렌드 확인됨: 자소서 폐지, AI 활용 역량·문제해결 과정 평가)은 결말의 제작기 링크 한 줄로 담백하게.
- 구현: SVG stroke 드로잉 + 체류 감지, 의존성 최소(Three.js 미사용).

## 결과

- 검토했으나 기각된 형식들: 스크립트 대화(조작 요구), 실 LLM 챗봇(통제 불가), 온도/데워지는 페이지(은유가 불가독), 퍼즐 쌍맞추기(노동), 예측 게임(선택 부담).
- 초상 선화는 현재 범용 일러스트 — 본인 사진 기반 커스텀 선화로 교체 여지.
- 콘텐츠 7문단은 플레이스홀더, UI 보며 확정(0018의 데이터 주도 원칙 유지 — `src/story.js`만 수정).
