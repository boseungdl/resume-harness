# 0020. 웹 포폴 형식 확정 — 걷는 사람 (3D 여정)

날짜: 2026-08-06

## 상태

승인됨 (ADR-0019 '한 붓 초상'을 대체. 포폴 이원화(0018)·콘텐츠 원칙은 유지)

## 맥락

한 붓 초상은 스크롤 동기화로 개선했으나 사용자가 전면 재구축을 결정: "3D 모델이 중앙에서 계속 걷고, 길이 보였다 잃기도 하고, 걸으면서 주변 배경이 하나씩 채워지는" 경험.

## 결정

**걷는 사람**: 무채색 마네킹(three.js Xbot, walk/idle 애니메이션)이 화면 중앙에서 계속 걷고, 스크롤이 걸음이 되어 세계가 지나간다.

- **길**: 챕터 구간 안에서는 보이고, 구간 사이(전환점)에서는 끊긴다 — 징검돌만 남는다. "길이 늘 보였던 것은 아닙니다. 그래도 계속 걸었습니다."
- **채워지는 세계**: 소품(나무·바위·덤불·가로등, 로우폴리 파스텔)이 걸어서 가까워질 때 하나씩 솟아난다. 구간이 진행될수록 팔레트가 차가움→따뜻함으로.
- **하늘**: 새벽→낮→노을로 여정과 함께 변화.
- **끝**: 광장에서 인물이 돌아서서 마주 보며 "다음 구간은 만나서 걷고 싶습니다" + 연락처.
- **NPC 문답 구조** (2차 반영): 콘텐츠는 스크롤 카드가 아니라 **길 위의 만남**이다. 구간마다 동글이 NPC가 물음표를 띄우고 기다리고, 다가가면 좌측 팝업에 질문("팀에서는 어떤 사람인가요?")과 답이 떠오르며, 지나가면 사라진다. 우상단 **"알게 된 것 n/7" 대시보드**에 지나친 만남의 요약 키워드가 영구히 채워진다 — 수집의 재미 + 끝났을 때 나에 대한 요약이 완성됨.
- **상징 랜드마크** (2차 반영): 구간 풍경이 그 챕터 내용과 맞물림 — 첫인상=서리 자작나무, 문제=갈림길 표지판, 준비=미리 놓인 등롱, 팀=모닥불과 통나무, 신뢰=끊긴 구간을 잇는 다리(유일하게 길이 안 끊기는 구간), 꾸준함=돌탑, 이유=창에 불 켜진 마을.
- 캐릭터는 Xbot 마네킹 → **RobotExpressive**(귀여운 로우폴리 로봇, 464KB)로 교체. 엔딩에서 돌아서서 손 흔듦(Wave).
- 구현: Three.js + GLTF(`public/models/`), 그림자·안개, 모델 로드 실패 시 프리미티브 폴백. 콘텐츠(질문·답·칩)는 `src/story.js` 하나로 관리, 플레이스홀더.
- **만남 게이트 (4차)**: NPC를 만나면 스크롤이 그 앞에서 물리적으로 멈추고, 답을 읽고 "계속 걷기" 버튼을 클릭해야 재개된다 — 읽지 않고 지나갈 수 없는 구조("공짜면 대충 넘긴다" 해법). 수집(클릭) 시 계기판·여정 노드가 채워진다. 우상단은 "PROFILE SYNC" 계기판: 수집률 %·만남 n/7·걸은 거리 m·여정 시간 KPI + 항목별 게이지. UX 원칙: 행동을 요구하는 버튼이 뜨는 동안 패널 부유 애니메이션 정지(클릭 타깃은 움직이지 않는다).
- **아트 디렉션 (3차): 해안 데이터로드** — "숲속 정적" 기각, 상쾌한 바다 + SF 융합으로 전환. 파도치는 로우폴리 바다·모래사장·부표, 시안 발광 엣지의 트랙, 빛기둥 가로등, 랜드마크 미래화(얼음 크리스탈·홀로그램 표지판·에너지 램프·부유 돌탑·등대 마을 — 모닥불은 따뜻함 유지). 하늘 상쾌한 청록 → 노을. UI는 홀로그램 HUD: 글래스 패널+코너 브래킷, 질문 타이핑 효과, 부유 모션, 발광 대시보드 칩. 서체 Noto Serif → IBM Plex Sans KR.

## 결과

- 기각 누적: 파티클 스크롤(0019), 한 붓 초상(이번). 한 붓 초상 코드는 git 이력에만 남음.
- Xbot은 무채색 마네킹으로 재질 통일 — "아직 채워지는 중인 사람"과 어울리고 얼굴 공개 문제도 없음.
- 남은 일: 문단 확정, 구간별 상징 소품(챕터 내용과 맞물리는 랜드마크), 배포.
