# 0023. 웹 포폴 랜딩 — 활자 한 컬럼 + 세계에 반납 (전면 재구성)

날짜: 2026-08-07

## 상태

승인됨 (0021·0022의 카드/홀로 패널 랜딩을 전면 대체. 정보 원칙·여정 구조는 유지)

## 맥락

0022의 라이트 FUI도 "30년차가 만든 퀄리티가 아니다" 판정. 3개 관점(타이포·컴포지션 / 미니멀리즘 장식 감사 / 3D 합성 아트디렉션) 전문가 리뷰가 수렴한 진단: 반픽셀 폰트 14종·전부 700 웨이트·장식 10계통 동시 가동·행마다 다른 그리드·유일한 자산(3D 세계와 로봇)을 블러와 패널로 매장. 장식 감사 결과 KILL 11 · REDUCE 6 · KEEP 2.

## 결정

- **레이아웃**: 카드·존·패널 전부 폐기. 좌측 640px 활자 단일 컬럼(이름 88px → 리드 20 → 숫자 한 줄 24 mono → 소개 2문장 15 → 정의목록 메타 13 → 텍스트 링크) + 우측은 3D 세계에 반납. 대비는 좌측 가로 스크림 하나.
- **연출**: 로봇이 관람자를 마주 보고(rotation −0.49) 시작 데크 위에 서서 로드 시 손을 흔든다. 카메라 A(눈높이 마주 보기 (-2.8,2.0,6.6))→B(동행 샷)를 스크롤 첫 0.9화면에 스크럽. 로봇→데크→CTA(화면 유일 버튼, left 70%)가 한 수직축. 전면 블러 삭제 — 심도는 fog near 18→22 lerp만.
- **물리 법칙**: UI는 스스로 빛나지 않는다(글로우·그라데이션 텍스트·text-shadow·스펙큘러·엣지 링 전부 삭제). 강조는 잉크(크기·웨이트), 유채색은 틸(시스템)+코랄(현재) — **코랄은 경로 브레드크럼의 현재 위치 점 1회**. 모션은 로드 1회 페이드와 호버 응답뿐, 무한 루프 0(걷기 샤인·카운트업·패럴랙스 리그·시계 삭제).
- **정보 처분**: 성장경로 다이어그램→한 줄 브레드크럼, 자격증 카드→메타 한 행, 도구 아이콘(skillicons)·"이 페이지도 직접" 문장·"3개 균등 문" 삭제(포폴·이력서는 텍스트 링크로 강등, 걷기가 유일 버튼). 커밋 차트→하단 풋라인 스파크라인(축 없음, 30px).
- world.js에 시작 데크 추가(z +7~−31) — 랜딩 프레임에서 길이 소실점으로 뻗는다.

## 결과

- 여정 UI(팝업·계기판·게이트)는 유리 패널 유지 — 변경 없음.
- 기각 누적: 홀로 패널 존(0022), 3+3 카드 그리드(0021), 장식 11종(감사 결과).
- 남은 일: 포폴·이력서 링크 연결, 7문답 실문장, 자격증 3종 실명, 배포.
