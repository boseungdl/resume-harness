# 0022. 웹 포폴 랜딩 — 라이트 홀로그램 FUI (박스 전면 제거)

날짜: 2026-08-06

## 상태

승인됨 (0021의 카드 그리드 스타일을 대체. 정보 구조·한 화면 90vh·여정 UI는 유지)

## 맥락

0021의 흰 카드 그리드가 "조잡해 보인다"는 사용자 판정. 원인: 정보 9개를 동일한 흰 라운드 박스에 담는 것은 관리자 템플릿 문법이고, 사용자가 원한 것은 "영화에서 보는 대시보드"(FUI). 다크는 이전에 기각됐으므로 밝은 해안 세계 위의 라이트 홀로그램으로 결정.

## 결정

- **박스 전면 제거**: 랜딩에서 카드(.panel) 폐기. 구획은 **존(zone)** — 상단 헤어라인 + 좌측 악센트 틱 + 옅은 블러 베일(보더·그림자·라운드 없음). 유리 뒤 3D 세계가 화면 전체의 배경.
- **FUI 문법**: 숫자·데이터는 IBM Plex Mono, 존 라벨은 모노 인덱스(01~06) + 소형 한글, 대시보드 외곽 헤어라인 프레임 + 코너 틱 2개(악센트), 초미세 설계도 그리드(52px, 3.5%), 우상단 **라이브 KST 시계**(실데이터 모션).
- **CTA**: 걷기 문만 악센트 보더+틴트+글로우+샤인 스윕 — 화면의 유일한 채움 요소.
- **차트**: 바 42%·플랫 코너·모노 축·점선 스플릿 — 계기판 톤.
- 틸트 제거(박스가 없으면 기울일 면도 없다). 스태거·카운트업·레일 드로우·패럴랙스는 유지.
- 여정 UI(팝업·계기판·진행 바)는 기존 유리 패널 유지 — 랜딩=관제화면, 여정=홀로그램 패널로 역할 구분.

## 결과

- 기각 누적: 다크 시네마틱(밝은 무드 유지), 하이브리드(톤 경계 난이도), 회전 텍스트 배지(정보 없는 장식 판정).
- 남은 일: 포폴·이력서 문 연결, 7문답 실문장, 자격증 3종 실명, 배포.
