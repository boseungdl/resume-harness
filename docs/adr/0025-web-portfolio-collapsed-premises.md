# 0025. 웹 포폴 — 심문 7문답을 버리고 "무너진 전제" 4전환점으로

날짜: 2026-08-11

## 상태

승인됨 (구조 확정. 본문 문장은 초안 — 사실 여부는 사용자 확정 대기)
ADR-0020(걷는 사람)은 유지, ADR-0024(친밀도 아크 7챕터)와 journey-v2(HR 심문 7문답)의 **콘텐츠 축을 대체**한다.

## 맥락

웹 포폴의 목적이 "기술 증명"에서 **"문제해결력 증명"**으로 좁혀졌다. 동시에 독자가
기술을 모르는 인사담당자·대표 한 사람으로 고정됐고, 프로젝트·스택·성과는 전부
PDF 포폴(`portfolio/index2.html`)로 내보내기로 했다.

문제는 기존 구조(HR이 묻고 지원자가 답하는 심문 7문답)로는 문제해결력이 원리적으로
안 보인다는 점이다. **답은 언제나 당연해 보인다** — 다 듣고 나면 "그렇게 하면 되지"로
끝나고, 판단의 난이도가 사라진다. 문제해결력이 보이는 순간은 독자가 **해결 이전 상태**를
먼저 봤을 때뿐이며, 그 전후의 거리가 곧 능력이다.

## 결정

**척추 = 무너진 전제 4개.** 세계에 지원자의 **틀렸던 판단이 구조물로 서 있고**, 걸어가면
그것이 무너지고 그 자리에 다음 문장이 선다. 잔해는 치우지 않고 길가에 남는다.

1. 화면이 전부인 줄 알았습니다 — (판단 장면 없음, 오프닝)
2. 만들면 끝인 줄 알았습니다 — 폐쇄망 현장 1인 상주: 기록·절차 고정 / 191명 오픈
3. 기술이 목적인 줄 알았습니다 — 파크골프: "시설 없는 동네 = 부족"이라는 자기 전제를 뒤집어
   공급을 개수가 아니라 **닿는 거리**로 재계산. 한계(수용 인원 미고려)를 스스로 기록
4. 문제는 주어지는 건 줄 알았습니다 — 크레인 현장 목격 → 주제 제안 → 팀장.
   문턱값 딜레마: 감지는 열어두고 **연속 관측 시에만 경보**. 대가는 초기 인식 지연

**보조 박자 = 대가의 저울.** 각 전환점 끝에 "대신 무엇을 포기했는가" 한 줄. 근거는
master-source §2-4 "결정마다 대가를 같이 적는다"(반복 행동).

**퀴즈·선택지 금지.** 독자에게 고르게 하면 시험이 되고, 정답 판정은 무례가 된다.
독자는 아무것도 하지 않고, 전제가 네 번 무너지는 것을 본다.

**시간·개수 비표기.** 연도·교육 회차·재직 기간을 쓰지 않는다. 서사를 척추로 세우면 독자는
자동으로 세기 시작하고, 그 순간 페이지는 문제해결력이 아니라 이력의 빈틈을 증명한다
(master-source §2-7: "여섯 번의 교육"은 본문 감점 — 4인 패널 만장일치).

## 왜 4개인가

3개면 "그냥 방향을 바꿨다"로 얇아지고, 6개 이상이면 세어진다. 4개는 방향의 일관성
(화면 → 뒤 → 사람 → 문제 정의)이 보이면서 개수가 인상에 남지 않는 구간이다.

## 결과

- 모든 전환점이 `"~인 줄 알았습니다"`로 시작한다. 이 형식 때문에 서사가 경력 나열이 아니라
  **한계를 매번 먼저 알아챈 기록**으로 읽힌다. 여러 번 옮긴 사람이 아니라, 매번 이유가 있던 사람.
- 태도 서술("저는 전제를 의심합니다")은 한 문장도 쓰지 않는다 — 네 번 무너지면 독자가
  그 문장을 스스로 만든다. 주장하지 않는 것이 이 구조의 존재 이유다.
- 종착: 잔해 전경 + PDF 포폴 다운로드 + 연락. 기술 질문은 PDF가 받는다.
- 기각: 독자 선택형 딜레마(퀴즈화), 교육 과정 단위 연대기(개수 노출),
  "어둠에서 그려지는 지도"를 척추로 삼는 안(첫인상이 "이 페이지 뭐지"가 됨 — 오프닝으로만 잔존).
